# AU Quest 🧭 — เว็บฝึกสอบทุน AU The Creator of Tomorrow (ประเภทสอบแข่งขัน)

## เปิดใช้
```bash
cd au-quest
npm install        # ครั้งแรกครั้งเดียว
npm run dev
```
เปิด `http://localhost:5178` ใน ego lite (หรือเบราว์เซอร์ไหนก็ได้)
- มือถือในวง Wi-Fi เดียวกัน: เปิด `http://<IP ของ Mac>:5178` (ดู IP ที่ขึ้นตอนรัน `npm run dev`) — ใช้ฝึกข้อสอบได้ทุกอย่าง แต่การอัดเสียงบนมือถือต้องเป็น https จึงควรฝึกพูดบน Mac
- ครั้งแรกจะเจอแบบทดสอบวัดระดับ 60 ข้อ 60 นาที ทำจบแล้วได้แผนรายวันถึงวันสอบ
- ครั้งแรกที่กดอัดเสียง เบราว์เซอร์จะถามสิทธิ์ไมค์ → กด Allow

## ใช้บนมือถือ / ทุกเครื่อง (เว็บออนไลน์)
ทุกครั้งที่ push ขึ้น branch `main` GitHub Actions จะ build และ deploy ขึ้น GitHub Pages ให้เอง (`.github/workflows/pages.yml`)
- iPhone / iPad: เปิดลิงก์ใน Safari → ปุ่มแชร์ → "เพิ่มไปยังหน้าจอโฮม"
- Android: เปิดใน Chrome → เมนู ⋮ → "ติดตั้งแอป" หรือ "เพิ่มลงในหน้าจอหลัก"
- เปิดครั้งแรกแล้วใช้ออฟไลน์ได้ (เสียงพากย์จะถูกเก็บไว้หลังเปิดฟังครั้งแรก)
- เวอร์ชันออนไลน์ใช้ระบบถอดเสียงของเบราว์เซอร์ (Web Speech) ส่วน Whisper ในเครื่อง, คำถามต่อเนื่องจาก AI และการเรียบเรียงคำตอบด้วย AI ใช้ได้เฉพาะตอนรันบน Mac (`npm run dev`)
- ความคืบหน้าเก็บในเครื่องแต่ละเครื่องแยกกัน ย้ายข้ามเครื่องได้ที่ ⚙️ ตั้งค่า → Export / Import

## ตั้งวันสอบ
ไปที่ ⚙️ ตั้งค่า → "วันสอบ" (ค่าเริ่มต้น 1 มี.ค. 2570 เป็นสมมติฐาน เพราะ AU ยังไม่ประกาศรอบ 2570) แผนทั้งหมดจะคำนวณใหม่เอง

## เสียงประกอบตอนเรียน
กดไอคอนแท่งเสียงที่หัวเว็บเพื่อเปิดปิด เลือกแนวและความดังได้ที่ ตั้งค่า → "เสียงประกอบตอนเรียน" มี 6 แนว (คอร์ดช้า เปียโน เสียงฝน pink noise brown noise binaural 10 Hz) ทุกแนวสังเคราะห์ในเบราว์เซอร์ ไม่มีเนื้อร้อง ใช้ได้ออฟไลน์ และเงียบเองตอนอัดเสียงพูด เหตุผลจากงานวิจัยอยู่ในหน้า "วิธีเรียนให้จำ" (`content/learn.json`)

## AI (ไม่บังคับ)
แอปใช้ได้ครบโดยไม่ต้องมี AI ถ้าอยากให้กรรมการถามต่อจากคำตอบจริง และช่วยเรียบเรียงคำตอบของเราเอง:
1. เปิด dashboard ของ 9Router → สร้าง/คัดลอก API key
2. เพิ่มบรรทัดใน `.env`: `NINEROUTER_API_KEY=...`
3. รัน `npm run dev` ใหม่ (ค่าเริ่มต้นใช้ `cx/gpt-6.1-terra` เปลี่ยนได้ใน ⚙️ ตั้งค่า)

## วางไฟล์ซับของตัวเอง
ถอดซับคลิปด้วยโปรแกรมบน Mac แล้วตั้งชื่อตาม id ของคลิป YouTube (ตัวอักษร 11 ตัวหลัง `v=`):
```
subs/<videoId>.srt   หรือ   subs/<videoId>.vtt
```
เปิดคลิปนั้นในหน้า 🎬 คลิปเสริม จะเห็นซับสองบรรทัด (อังกฤษ + ไทย) ซิงก์กับคลิป คลิกคำเพื่อดูความหมายและเก็บเข้าคลังศัพท์ ⭐ — มีไฟล์ตัวอย่าง `subs/GV9IFkjsQkE.srt`

## เติมเนื้อหา
เนื้อหาทั้งหมดเป็น JSON ใน `content/`:
| ไฟล์ | คืออะไร |
|---|---|
| `lessons/Lxx.json` | ด่านไวยากรณ์ 7 ขั้น + โจทย์ 25 ข้อ + โจทย์พลิก |
| `cloze/Cxx.json` | cloze 10 ช่อง (`"mock": "M01"` = สงวนไว้ใน mock) |
| `reading/Rxx.json` | บทอ่าน (ใส่ `**คำ**` เพื่อทำตัวหนา) |
| `mocks.json` | ชุด mock = cloze 3 + reading 3 |
| `interview.json` | คำถามสัมภาษณ์ + ประโยคเอาตัวรอด |
| `shadowing.json`, `videos.json`, `games.json`, `land-films.json` | อื่น ๆ |

ทุกข้อต้องมี `skill`, `difficulty` (1–3), `explanation_th`, `why_wrong` (เหตุผลของตัวเลือกผิดทั้ง 3 ตัว, ตัวที่ถูกใส่ `null`)

```bash
npm run add:questions -- ไฟล์ใหม่.json   # รวมโจทย์ใหม่เข้าด่าน/คลัง แล้วตรวจ
npm run validate                         # ตรวจว่าทุกข้อครบ + ไม่มีข้อความลอกจากข้อสอบ PDF
npm run check:answers                    # (ต้องมี NINEROUTER_API_KEY) ให้ AI อีกตัวตรวจว่ามีคำตอบถูกข้อเดียวจริง
npm run generate:audio                   # สร้างเสียง ElevenLabs ที่ยังขาด (ไม่จ่ายซ้ำ) ดู AUDIO_REPORT.md
npm test                                 # unit test (SRS, แผน, การวิเคราะห์เสียงพูด)
```

## สำรองข้อมูล
ความคืบหน้าและไฟล์เสียงที่อัดอยู่ในเบราว์เซอร์ (IndexedDB) → ⚙️ ตั้งค่า → Export / Import (ไฟล์ .json เดียว รวมเสียง)

## ความปลอดภัยของ key
- `ELEVENLABS_API_KEY` อยู่ใน `.env` ที่เดียว (`.gitignore` แล้ว) ถูกอ่านโดยเซิร์ฟเวอร์ Node เท่านั้น ไม่ถูกส่งไปเบราว์เซอร์
- ถ้าจะแชร์โปรเจกต์ ห้ามแชร์ไฟล์ `.env`

## เปิดอัตโนมัติ (ตั้งไว้แล้ว)
แอปรันอยู่ตลอดผ่าน LaunchAgent `~/Library/LaunchAgents/local.auquest.plist` — เปิดเครื่องแล้วเข้า http://localhost:5178 ได้เลย ไม่ต้องพิมพ์ `npm run dev` (ถ้าล่มจะเปิดใหม่เองใน ~10 วินาที, log อยู่ที่ `~/Library/Logs/auquest.log`)

ถ้าต้องการหยุด:
```bash
launchctl bootout gui/$(id -u)/local.auquest
```
เปิดกลับ:
```bash
launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/local.auquest.plist
```
